Reliant Overview

Reliant sponsors self-storage programs for 1031 exchange investors. The firm profile below is deliberately short: Baker 1031 publishes assets under management, founding year and headquarters for a sponsor only once those have been confirmed against the sponsor’s own materials, and that work is still open for Reliant. What is on this page instead is the part that has been verified — the completed programs, recomputed from the sponsor’s own offering documents on the same basis used everywhere on this site.

How to read this track record

Reliant’s average is the highest of any sponsor in the dataset, and the reason matters more than the number. The programs are concentrated in one property type, self-storage, over a period when storage values rose sharply, and the average hold is short, which lifts a simple annual return computed as (equity multiple − 1) ÷ holding period. Read it as a description of that run in that sector, not as a rate a storage program is expected to earn next.

This describes the sponsor’s focus only, and should be weighed against the risks common to DST investments — illiquidity, loss of principal, and no guaranteed distributions. Full risk factors are in each offering’s Private Placement Memorandum.
