# Working With a Real Estate Agent on a 1031 Exchange

I keep seeing a familiar assumption: a good real estate agent can make an exchange work because a good agent can make an ordinary sale work. The assumption misses a practical point. In a 1031 exchange, a perfectly ordinary closing can damage the deferral if the QI is not engaged, the proceeds go to the wrong place, or the replacement search begins too late.

Baker 1031 Research updated this 1031 Exchange guide in June 2026. It is a 16 min read. A 1031-aware agent sells the relinquished property and helps acquire the replacement while understanding the 45-day identification and 180-day closing deadlines, QI coordination, and the need to find replacement property quickly. An agent who does not understand those things can inadvertently put the deferral at risk.

First-order thinking asks whether the agent can market the sale or find a property. Second-order thinking asks whether the contracts, closing, proceeds, title, and replacement search all remain compatible with the exchange rules. The agent can be excellent at real estate and still need the QI, CPA, attorney, advisor, and securities professionals around the transaction. The issue is not replacing the agent. It is making the team complete.

## Why a 1031-savvy agent matters

A [1031 exchange](1031-exchange-guide.html) adds requirements an ordinary real estate transaction may not expose. The 45-day identification period, the 180-day closing period, coordination with the [qualified intermediary](what-is-a-qualified-intermediary.html), the same-taxpayer rule, and like-kind requirements all affect how the sale and acquisition must be handled. An exchange-aware agent works within those constraints. An unaware agent can unintentionally put the deferral in jeopardy.

The risk is concrete. An agent may fail to bring the QI in before the relinquished-property closing, mishandle the timing, underestimate the urgency of the replacement search, or structure the transactions in a way that conflicts with the exchange. Because the tax benefit depends on following the rules, a closing without the QI in place—or a search that begins after the sale—can be much more damaging than it would be in an ordinary deal.

A 1031-savvy agent anticipates the mechanics: the QI is engaged before closing, the deadline pressure is understood, replacement property is sourced with the clock in mind, and the agent coordinates with the advisory team. At a minimum, an agent should be exchange-aware, willing to coordinate with the QI and advisors, and willing to defer to them on the exchange mechanics. The right agent supports the exchange; the wrong one can hinder it.

## What the agent does in an exchange

The agent’s role is centered on the property transactions. On the sale side, the agent markets and sells the relinquished property, coordinating the closing with the QI so proceeds go to the QI rather than the seller. On the acquisition side, the agent helps source, evaluate, and acquire the replacement property inside the applicable deadlines.

The exchange-specific work includes ensuring the QI is in place before the relinquished closing, including exchange cooperation language in the relevant contracts, coordinating the closings so proceeds flow through the QI, and keeping the schedule visible throughout. The agent does not run the exchange mechanics—that is the QI’s job—and does not provide the tax analysis—that is the CPA’s job. The agent makes the property transactions compatible with the exchange.

The agent is also a central sourcing channel. Market knowledge, local relationships, and the ability to surface opportunities rapidly can make the difference when there are 45 days to identify a replacement. The division of labor is straightforward: the agent handles real estate transactions and replacement search; the QI handles exchange mechanics; the CPA handles tax. An exchange-aware team understands those boundaries and coordinates across them.

## Coordinating with the QI and timeline

The QI must be engaged before the relinquished property closes. That is what allows proceeds to go to the QI rather than the seller. If a closing occurs without the QI in place and the seller receives the proceeds, the exchange can be disrupted. The agent must coordinate the closing with the QI’s involvement rather than treating the exchange as a post-closing choice.

The calendar matters just as much. The [45-day identification](1031-exchange-identification-rules.html) clock starts when the relinquished property closes, while the 180-day closing clock runs concurrently. An agent who understands this will search with urgency in the first window and coordinate the replacement closing in the second. The deadlines do not move because a suitable property is hard to find.

The agent should communicate with the QI about closings, with the CPA about tax-relevant transaction details, and with the investor about criteria, search progress, and timing. This is coordination, not a claim that the agent assumes the QI’s or CPA’s function. It is what helps the property transaction support, rather than disrupt, the exchange.

## Finding replacement property through your agent

Finding a replacement inside the 45-day window is one of the agent’s most useful contributions. The agent’s market knowledge, network, and access to listed and off-market properties can make the agent a primary channel for direct-property replacements. An agent who has clear criteria and understands the deadline can prioritize the search and surface candidates sooner.

The investor should make those criteria specific: desired property type, market, price, income goals, and any other constraints. The search should begin early, ideally before the relinquished property is sold. A candidate list built before the sale makes the first 45 days a period of evaluating prepared options, not a first attempt to define the target.

The agent’s work should not be the only channel. Listings, DST sponsors, and the investor’s own network can widen the search. The agent is often the primary direct-property scout; DSTs can provide passive replacements or a backup through the appropriate securities professionals. Broader sourcing does not dilute the agent’s role. It reduces the risk that one narrow channel leaves the investor without a workable replacement.

## Commission and cost considerations

The agent’s commission and related transaction costs have exchange implications. Selling costs such as the agent’s commission, and acquisition costs, are generally exchange expenses that can be paid from exchange proceeds without creating taxable [boot](what-is-boot-1031-exchange-how-to-avoid.html). In ordinary circumstances, commissions, title, escrow, and recording costs are exchange expenses rather than taxable boot.

There are important details. Financing costs and prorations may receive different treatment, and the overall handling should be coordinated with the QI and CPA. The point is not that every cost has identical treatment. It is that an agent’s commission is generally a normal, non-boot exchange expense rather than a reason the deferral fails.

From a capital-management perspective, the commission belongs beside other transaction costs. A capable agent earns it by sourcing property effectively and handling the transaction with the exchange’s constraints in mind. It should be evaluated together with the agent’s experience, responsiveness, network, and ability to coordinate—not merely as a percentage on a closing statement.

### Key takeaways

- A 1031-savvy agent matters because exchange rules affect how transactions are handled; the wrong agent can jeopardize the deferral.
- The agent handles the property transactions and replacement search. The QI handles exchange mechanics, and the CPA handles tax.
- The QI must be engaged before closing, and the agent must work within the fixed 45- and 180-day deadlines.
- An agent’s commission is generally a non-boot exchange expense. Effective sourcing and coordination are the practical value behind the cost.

## When you need more than an agent

An exchange commonly needs more than an agent. The agent handles the property transaction and direct-property sourcing. The QI handles the exchange mechanics. The CPA addresses tax. An attorney may be needed for structuring. The agent is an important member of the team, but not the complete solution.

The gap is especially clear with passive replacements. An agent usually sources direct real estate. Passive options such as DSTs come from sponsors and broker-dealers, and they require a securities-licensed professional because DSTs are securities. An investor considering a DST as a primary passive investment or a backup needs that additional expertise.

The relevant question is not whether the agent alone is sufficient in the abstract. It is whether the transaction has all of the support it needs: property sourcing, exchange mechanics, tax analysis, legal structuring where appropriate, and access to passive alternatives if those are part of the plan. An agent is a key player. A successful exchange is a team effort.

## Frequently Asked Questions

### Do I need a 1031-experienced agent?

It is strongly preferable. The deadlines, QI coordination, same-taxpayer rule, and like-kind rules affect transaction handling. An experienced agent navigates these requirements; an inexperienced one can jeopardize the deferral, including by closing before the QI is involved. At minimum, the agent should be exchange-aware, coordinate with the QI and advisors, and defer on exchange mechanics.

### What does the agent do in a 1031 exchange?

The agent handles the real estate transactions: selling the relinquished property and acquiring the replacement inside the exchange framework. The agent coordinates closings with the QI, includes exchange cooperation language in contracts, and sources replacement property. The QI handles the exchange mechanics, while the CPA handles tax.

### How does the agent coordinate with the QI?

The agent helps ensure the QI is engaged before the relinquished property closes so proceeds go to the QI rather than the seller. The agent then coordinates closings with the QI’s involvement and works within the deadlines. A closing without the QI can disrupt the exchange.

### Can my agent help me find replacement property?

Yes. The agent is a primary source for direct replacement property, using market knowledge and a network that may include off-market opportunities. Communicate criteria clearly, begin early, and make the deadline urgency explicit. Listings, DST sponsors, and personal networks can add other channels.

### Is the agent's commission a boot problem?

Generally, no. The agent’s commission and ordinary transaction costs such as title, escrow, and recording are generally exchange expenses payable from exchange proceeds without taxable boot. Financing costs and prorations can be treated differently, so the QI and CPA should coordinate the overall cost treatment.

### When do I need more than an agent?

Almost always. Beyond the agent, the exchange needs a QI for mechanics, a CPA for tax, and sometimes an attorney for structure. Passive replacements or DST backups also require DST sponsors or a securities-licensed professional. The agent is one member of the full team.

### Can my agent sell me a DST?

Generally, no. DSTs are securities and require a securities-licensed professional working through a broker-dealer, not a typical real estate agent licensed only for real estate. The agent handles direct property; the securities professional provides the DST options.

### What if my agent doesn't know 1031 exchanges?

The agent can still be part of the process if they will coordinate with the QI and advisors and defer on exchange mechanics. The investor must ensure the QI is engaged before closing and the deadlines are respected. An exchange-experienced agent, or an inexperienced agent supported by strong QI and advisor coordination, reduces the timing and QI risk.

### How early should I involve my agent?

As early as possible, ideally before listing or selling the relinquished property. Early involvement lets the agent begin sourcing and build a candidate list, so the investor evaluates prepared choices when the 45-day window begins rather than starting from scratch.

### Does the agent handle the exchange paperwork?

No. The QI handles the exchange agreement, assignment, and identification. The agent handles property-transaction documents such as listings and purchase contracts, including exchange cooperation language. The CPA handles tax reporting on Form 8824. The agent’s documents support the exchange; they are not the exchange mechanics.

### Should my agent coordinate with my CPA and QI?

Yes. The agent should coordinate with the QI about closings and timing and communicate with the CPA about tax-relevant details. The agent handles property transactions, but those transactions must align with the QI’s mechanics and the CPA’s tax treatment. A coordinated agent, QI, CPA, and advisor team helps the parts fit together.

### What should I look for when choosing a 1031 agent?

Look for documented exchange experience: ask how many exchanges the agent has handled. Ask about familiarity with the 45- and 180-day deadlines, QI coordination, and the ability to source replacements, including off-market options. A good sign is an agent who can explain how closings will be coordinated with the QI and how replacements will be sourced quickly. Avoid someone who is unfamiliar with exchanges and unwilling to defer on the mechanics.

### Can the same agent handle both the sale and the purchase?

Yes. It is common for one agent to handle the sale of the relinquished property and acquisition of the replacement, which can streamline coordination because that agent knows the entire timeline. Separate agents may be appropriate in different markets. Either way, the agent or agents must understand the exchange, coordinate with the QI, and respect the deadlines on both sides.

### Does using an agent affect my exchange timeline?

The deadlines do not change: they remain 45 and 180 days. A good agent can improve the odds of meeting them by sourcing replacements quickly and coordinating closings well. A poor or exchange-unaware agent can create delay or mishandle QI coordination. A responsive agent involved early is a meaningful schedule advantage.

### What if my agent and QI disagree on handling something?

On exchange mechanics, the QI’s guidance should generally prevail because the QI specializes in the rules while the agent handles property transactions. Tax or legal questions should be resolved with the CPA or attorney. The team needs to align because the deferral depends on following the mechanics correctly.

## Glossary

### 1031-Savvy Agent

A real estate agent who understands exchange deadlines, QI coordination, and like-kind rules.

### Relinquished Property

The property the agent sells in the exchange, with closing coordinated with the QI.

### Replacement Property

The property the agent helps acquire, sourced within the deadlines.

### Qualified Intermediary (QI)

The party handling exchange mechanics and the party with whom the agent coordinates closings.

### Exchange Cooperation Language

Contract language acknowledging the exchange that the agent includes in the property documents.

### 45-Day Identification Window

The deadline that makes the replacement search urgent.

### 180-Day Exchange Period

The deadline within which the replacement property must close.

### Exchange Expense

A transaction cost, such as commission, generally payable from exchange proceeds without boot.

### Boot

Taxable value received in an exchange. Most ordinary transaction costs are not boot, although some costs are treated differently.

### Off-Market Property

An unlisted property the agent may access through the agent’s network.

### Commission

The agent’s fee, generally a non-boot exchange expense.

### Sourcing Channel

A way to find replacements. The agent is a primary direct-property sourcing channel.

### Delaware Statutory Trust (DST)

A securities replacement option available through sponsors and beyond the typical agent’s scope.

### Exchange Team

The agent, QI, CPA, attorney, and securities professionals who support the exchange.

### Same-Taxpayer Rule

The requirement that the same taxpayer sell the relinquished property and acquire the replacement.

### Securities-Licensed Professional

The professional required to offer DSTs, complementing the agent’s direct-property work.
