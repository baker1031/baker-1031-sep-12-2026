# 721 Exchange Valuation: How Your Property Is Priced

[Home](baker1031.html) › Insights › 721 Exchange Valuation: How Your Property Is Priced

[Back to All Insights](insights.html)

**721 Exchange · Baker 1031 Research · Updated June 2026 · 16 min read**

I have been thinking about the quiet math beneath a 721 exchange. A property owner can focus on deferral, diversification, and future liquidity, but the number of OP units received is set by one economic question: what is the property worth relative to an OP unit?

First-order thinking treats valuation as paperwork before the transaction. Second-order thinking recognizes it as the price at which the investor trades a concentrated asset for a stake in a REIT. In a 721 exchange, property value determines how many OP units an investor receives. This guide explains why that matters, how property and unit values are set, how units are calculated, how to negotiate, and how to test fairness.

## Why valuation matters

Valuation is the economic heart of a 721 exchange. It determines the number of [OP units](op-units-explained.html) received for the contributed property. The formula is simple:

`OP units received = agreed property value ÷ OP unit value`

A higher property valuation produces more units and more value for the owner; a lower valuation produces fewer. The valuation therefore sets the economic terms of the exchange.

Those units represent the investor's stake in the REIT, including future income, appreciation, and value. An unfairly low valuation means fewer units than the property warrants. A fair valuation gives the investor an appropriate stake. The valuation is not a formality. It is the determinant of the value received in the [721 exchange](721-exchange-guide.html).

## How property value is determined

Property value is typically determined through appraisal and negotiation between the owner and the REIT, early in [the exchange timeline](721-exchange-timeline-and-closing-process.html). The REIT, as acquirer, and the owner, as contributor, must agree on the value. Professional appraisals—estimating market value from income, comparables, and other methods—and the property's financials, including income and operating performance, generally inform that agreement.

The negotiation has two interests in tension. The owner wants a fair or favorable property value because it yields more units. The REIT wants a sound acquisition value. Appraisals and financials provide the basis for the agreed figure.

Important inputs include net operating income, market value from appraisals and comparable properties, condition, location, and fit with [the REIT's diversified portfolio](diversified-reits-explained.html). In that sense, the property is valued like any commercial real-estate acquisition: through professional valuation and negotiation.

> Property value emerges from appraisal-informed negotiation between the owner and the REIT. The owner wants a fair value and more units; the REIT wants a sound acquisition value; appraisals provide the basis.

## How unit value is determined

The OP unit value is the per-unit value used to calculate the number of units received. It is typically tied to a REIT's net asset value (NAV) per share or, for a publicly traded REIT, its share price. OP units often convert one-for-one into REIT shares, so unit value generally reflects REIT share value.

For a publicly traded REIT, the share price and unit value are market-determined and transparent: the current share price can be observed. For a non-traded REIT, unit value is based on the REIT's periodic NAV estimate, which is less transparent. The relevant question is therefore whether the REIT uses a transparent market price or periodic NAV.

Property value and unit value together determine the units issued. The property appraisal and negotiation establish the first input; NAV per share or market price establishes the second.

## Calculating the units received

Once both inputs are known, the calculation is mechanical. If a property is valued at **$5,000,000** and OP units are valued at **$50** each, the investor receives **100,000** OP units:

`$5,000,000 ÷ $50 = 100,000 OP units`

The calculation converts property value into a specific number of units. A higher property valuation or lower unit value produces more units, and the reverse is also true. The number of units multiplied by unit value equals the property's contributed value. At issuance, the units are worth the value at which the property was contributed.

## Negotiating the valuation

Because property valuation affects units, negotiating it is an important part of a 721 exchange. The owner and advisors should seek a fair valuation that reflects true worth; the REIT seeks a sound acquisition value. The agreed figure, informed by appraisals and financials, is recorded in [the contribution agreement at closing](721-exchange-closing-documents-explained.html).

Effective preparation means understanding the property through an independent appraisal or analysis, presenting strengths such as strong income, location, and quality, and using advisors—a securities professional and potentially an appraiser—to advocate for fairness. Because valuation determines units and value, the negotiation directly affects what the investor receives.

The unit value is usually less negotiable because it is tied to REIT NAV or share price. The property value is normally the principal negotiable term.

## Key Takeaways

- Valuation determines the OP units received—property value divided by unit value—and is the economic heart of the 721 exchange.
- Property value is set through appraisals and negotiation between the owner and REIT.
- Unit value is tied to NAV per share for a non-traded REIT or market share price for a traded REIT.
- Negotiate property value so it fairly reflects the property's worth; it directly determines units and value.

## Valuation fairness considerations

A fair valuation means the property is valued at true market worth and unit value fairly reflects the REIT's per-share value. Both sides of the equation matter.

An investor can assess fairness by obtaining an independent appraisal, comparing that result to the REIT's offered value, understanding the unit value and how it is determined, and having advisors review the terms. For a non-traded REIT, NAV methodology deserves particular scrutiny because NAV determines unit value.

If the property appears undervalued or unit value appears questionable, the investor can negotiate, seek a better valuation, pursue a different REIT or opportunity, remain in direct real estate, or reconsider the exchange. Independent appraisal and advisor review protect against an unfair valuation.

## Frequently Asked Questions

### How is my property valued in a 721 exchange?

Through appraisal and negotiation between the owner and REIT. The parties agree on property value using professional appraisals, which estimate market value from income, comparables, and other methods, along with property financials, income, and performance. The owner seeks a fair value and the REIT seeks a sound acquisition value. This is the same broad approach used for commercial real-estate acquisitions.

### Why does the valuation matter so much?

It directly determines OP units: agreed property value divided by unit value. Higher property value means more units; lower value means fewer. Because units represent the investor's stake in the REIT, future income, appreciation, and value, valuation determines how much of the REIT the investor receives for the property.

### How is the OP unit value determined?

It is typically tied to NAV per share or, for a publicly traded REIT, market share price. Because OP units often convert one-for-one into REIT shares, the unit value reflects REIT share value. For a traded REIT, it is market-determined and transparent; for a non-traded REIT, it is the periodic NAV estimate. Unit value plus property value determines units received.

### How many OP units will I receive?

The answer is agreed property value divided by OP unit value. A **$5,000,000** property with **$50** units yields **100,000** units: **$5,000,000 ÷ $50**. Those units are worth, at issuance, the contributed property value. A higher property value or lower unit value produces more units. Advisors should confirm the calculation for the specific exchange.

### Can I negotiate my property's valuation?

Yes. Property value is negotiated, and the owner can advocate for a fair or favorable value. The owner should understand property value through an appraisal or analysis, present evidence such as strong financials, comparables, location, and quality, and have advisors support the case. Unit value is generally less negotiable because it is tied to NAV or share price, so property value is the main focus.

### How do I know if the valuation is fair?

Assess both property and unit value. Obtain an independent property appraisal and compare it with the REIT's offer. Understand NAV or share price and the method producing it; for a non-traded REIT, scrutinize NAV methodology. Have advisors review the terms. If the property is undervalued or the unit value seems questionable, negotiate or reconsider.

### What if I think my property is worth more than the REIT's offer?

Negotiate using evidence: an independent appraisal, strong financials, and comparables. Property value is negotiated, so the investor can argue for higher value and more units. If the REIT will not meet fair value, the investor can seek a different REIT or opportunity or reconsider the exchange. The investor should not accept an unfair valuation merely to complete the transaction.

### Is the unit value negotiable?

Generally, not much. Unit value is tied to NAV per share or market share price and reflects the REIT's own valuation rather than a negotiated term. Market price is objective for a traded REIT; periodic NAV is set by the non-traded REIT. The owner should still understand and scrutinize unit value, especially non-traded NAV, even though the property valuation is the main negotiable term.

### How does the valuation affect non-traded REIT exchanges?

For a non-traded REIT, unit value is periodic NAV rather than a transparent market price. The owner should understand NAV calculation and whether it fairly reflects REIT value because it affects units received. Property value is still negotiated. The NAV methodology is an added fairness consideration when there is no continuous market price.

### Should I get my own appraisal?

It is often prudent. An independent appraisal estimates property value, tests whether the REIT's offer is fair, and supplies evidence for negotiation. Since property value determines units, independent valuation evidence can strengthen the investor's position. Advisors can help arrange and interpret the appraisal.

### Does my property's debt affect the valuation?

Yes. If the property has a mortgage, valuation typically considers gross property value and debt. Equity—gross value minus debt—determines net units after the partnership assumes debt or takes the property subject to debt. Debt affects net contributed value and units, and debt assumption or partnership liabilities can have tax implications. Advisors and the CPA should handle debt treatment.

### How often is the unit value (NAV) updated for non-traded REITs?

Non-traded REITs typically update NAV periodically, often quarterly or annually, and some update more frequently. Unit value reflects the most recent NAV estimate. Because NAV is periodic rather than continuous, valuation timing relative to an update can matter slightly. Investors should check NAV frequency and methodology for currency and fairness. A traded REIT instead uses continuous market price.

### What if the REIT's offered valuation seems too low?

Negotiate or reconsider. If property value appears below true worth based on appraisal and analysis, present the appraisal, financials, and comparables to argue for a higher value. If fair value is unavailable, pursue a different REIT or opportunity, remain in direct real estate, or use a different strategy. Be willing to walk away from an unfair value.

## Glossary

**Valuation**  
The pricing of contributed property, determining OP units received.

**Property Value**  
The property's agreed value, set by appraisal and negotiation.

**OP Unit Value**  
The per-unit value tied to REIT NAV or share price.

**Net Asset Value (NAV)**  
The REIT's per-share value and the unit value for non-traded REITs.

**Share Price**  
The market price and unit value for traded REITs.

**Appraisal**  
A professional estimate of property market value.

**Units Received**  
Property value divided by unit value: the investor's stake.

**Negotiation**  
The process of agreeing on property value.

**Fairness**  
Valuation reflecting true property worth and fair unit value.

**Comparables**  
Values of similar properties used in appraisal.

**Net Operating Income**  
Property income and a valuation factor.

**Independent Appraisal**  
The investor's own appraisal for assessing fairness and negotiating.

**Contributed Value**  
Property value, equal to units multiplied by unit value.

**Non-Traded REIT NAV**  
The periodic value estimate that should be scrutinized for fairness.

**Negotiable Term**  
Property value, the main term the owner can negotiate.

**Advisor Advocacy**  
Advisors arguing for fair property valuation.
